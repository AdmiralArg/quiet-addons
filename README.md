# Quiet addons for WoW Forever

Small, calm addons for World of Warcraft: Forever. Each does one thing, then keeps out of your way.

| | |
|---|---|
| **Quiet HUD** | Fades the interface while you explore. A fight or a target brings it back. |
| **Quiet Names** | Softer names over heads, in a font you like. |
| **Buff Glow** | A buff you let drop pulses on its button; the move to press next gets a soft ring. Every class. |
| **Zone Levels** | Each zone's level range, on the world map. |
| **Quiet Bags** | What your other characters carry: bags, bank and mail. |
| **Quiet Friends** | Your friends' full names, one click away when you write a letter. |
| **Quiet Pins** | Notes on the map, and /way. |
| **Quiet Fishing** | One button fishes: pole out, cast, reel in, weapon back. |
| **Quiet Professions** | The cheapest way to level a crafting profession, at today's prices. |
| **Quiet Auctions** | Steady gold from the auction house, on the characters you choose. |

## Install

1. Download **Quiet-addons.zip** from the [newest release](https://github.com/AdmiralArg/quiet-addons/releases/latest).
2. With the game closed, unzip it into `World of Warcraft\_forever_\Interface\AddOns`.
3. Log in: a window lists the addons with a switch beside each. Keep the ones you want.

## Update

Double-click **Update Quiet** in your AddOns folder, with the game closed. It fetches the newest release and replaces
the Quiet addons' folders; your settings stay as they are.
